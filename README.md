**Intro To Miniedit**
_miniedit_ is an experimental text editor made with love2D, a lua framework.


**How To Download**

This is available on my itch.io page too: minidavid.itch.io/miniedit-text-editor for an easier install.

However this github page has the latest code but more complex to get up and running.

i. Just go to that green code button and download the zip. Or if you know how to clone it, do so.

ii. Download love2d. Head over to love2d website.

- Optional for tts and Speech to text -
- 
iii. Download Python

iv. In python with the "pip install" command, install vosk, pyttsx3 and espeak-ng

- -

v. Finally, open the location in which you downloaded the zip file in your terminal.

vi. Then type love .
The love2d file will automatically open the app.

--------
**How to Use the Text Editor**

There is a box for the title of the file.

Above it exists a circle to adjust typing speed. Shove it to the right to make it the slowest.

Miniedit uses a square brackets system. For example if your keyboard key a doesn't work, you just type b-1 within square brackets to get a.

It has a calculator like 1-1 that uses squarebrackets, supports utf8 and has math and physics equations too.

You can sort data alphabetically, replace words and more. It has a link to a website of tutorials I made called Documentation.
